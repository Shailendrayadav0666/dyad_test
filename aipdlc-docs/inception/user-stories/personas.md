# Personas — AT-793 Light / Dark Theme Toggle

## End User
- **Role**: Any user of the RAG exam-prep chatbot UI (uploading documents, asking questions, reading answers).
- **Characteristics**: Uses the app in varying lighting conditions/environments; no special technical role or permission level — single undifferentiated user type for this feature (per epic brief: "All end users of the UI — no role distinction").
- **Motivation**: Wants visual comfort while studying (e.g., switching to dark mode in low light) and a UI that feels modern and polished.
