## Future Scope

The Operations phase will eventually include:
- Deployment planning and execution
- Monitoring and observability setup

- Maintenance and support workflows
- Production readiness checklists

## Current State

Build and test activities are owned by the parallel **SDET track**, not by any phase — SDET runs them
per story with the **`/sdet-implement`** skill while development is still in progress, and signs merged, tested
stories off with **`sdet-list-work`**.

The ai-pdlc development workflow currently ends after CONSTRUCTION (per-story code generation and
optional code review/remediation).
